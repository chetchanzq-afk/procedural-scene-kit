# 05 · 性能门槛

程序化场景的成本在运行时，不在下载。必须设硬门槛，否则生成器会产出"好看但跑不动"的场景。

## 硬指标

| 指标 | 预算 | 获取方式 |
|---|---|---|
| Draw calls | ≤ 8（静态合批后通常 2–4） | `__stats().calls` |
| 三角面 | 小场景 ≤ 120k，街区 ≤ 250k，大外景 ≤ 400k | `__stats().tris` |
| 帧时 | 桌面 ≤ 16.7 ms，移动 ≤ 22 ms | `__stats().ms` |
| 程序数 | ≤ 12 | `__stats().programs` |
| 报错 | 0 | `__stats().errors` |

达标方式不是降画质，而是减实例、减分段、合并几何。

## 画质档位

| 档 | DPR | MSAA | 阴影 | Bloom 迭代 | AO | 细节 | 适用 |
|---|---|---|---|---|---|---|---|
| low | 1.25 | 0 | 1024 | 1 | 关 | 0.5 | 手机、集显 |
| medium | 1.5 | 0 | 2048 | 2 | 开 | 0.8 | 轻薄本 |
| high | 2.0 | 4* | 4096 | 2 | 开 | 1.0 | 独显 |
| ultra | 2.0 | 4* | 4096 | 3 | 开 | 1.0 | 桌面高配 |

\* 开 AO 时会强制关闭 MSAA（深度纹理不能挂在多重采样缓冲上）。需要抗锯齿就提高渲染倍率，或后续加 FXAA。

`quality.apply(name, sun)` 会同时改像素比、阴影图、Bloom 与 RT 采样数。

## 动态分辨率

每帧统计平滑帧时：

- 平均 > 22 ms：倍率 −0.1（最低 0.6）
- 平均 < 16.5 ms：倍率 +0.05（最高 1.0）
- 变更后有 2–4 秒冷却，避免抖动

倍率只影响渲染分辨率，不影响几何与光照，所以画质变化是渐进的。

## 合并策略

- 所有静态件在 `level.build()` 合并：N 个物件 → 1 个 draw call
- 发光件单独合并：+1 个 draw call
- 需要独立动画的件不合并，但数量控制在 20 以内
- 同一道具的大量小件写进生成函数的循环，不要摆放成百上千个实例

## AO 成本

- 半分辨率 12 采样 + 竖向/横向两次模糊，约 3 个全屏 pass
- 低档关闭，中档起开启；室内收益最大，开阔外景可适当降低强度
- 半径超过 1.0 会出现噪点和黑边，室内建议 0.35–0.5
- AO 开启时 MSAA 必须关闭，边缘锯齿靠分辨率倍率或 FXAA 解决

## 运动模糊与体积光成本

| 通道 | 成本 | 档位 |
|---|---|---|
| 运动模糊 | 全分辨率 8 taps，1 个全屏 pass | 低档关，其余开 |
| 屏幕空间光柱 | 1/4 分辨率 16 taps + 掩膜，2 个 pass | 低档关，其余开 |
| 几何光片 | 每束 2 个三角面 + 1 次混合绘制 | 始终可用 |

运动模糊会让画面轻微发软，`shutter` 不要超过 0.4；光片数量建议 ≤ 8 束，太多会过曝并增加混合开销。

## 常见性能坑

| 现象 | 原因 | 处理 |
|---|---|---|
| Draw calls 暴涨 | 忘了调用 `level.build()` | 合并 |
| 帧时高但三角面低 | 阴影贴图过大 / Bloom 迭代过多 | 降档或降阴影 |
| 远处闪烁 | 阴影相机范围太小 | 扩大 `shadow.camera` |
| 移动端发热 | DPR 2 + MSAA 4 | 强制 low |
| 材质编译卡顿 | 每个道具用了不同材质 | 全部走顶点色，共用材质 |
| 雾很浓仍能看到远处 | 雾密度与远裁剪不匹配 | 调 `camera.far` 与雾密度 |

## 测量方法

```js
window.__stats()
// { calls, tris, programs, res, scale, quality, theme, fps, ms, props, colliders, errors }
```

固定机位测三档：

```
?shot&q=low&cam=-26,8.5,32,0,4,-2
?shot&q=high&cam=-26,8.5,32,0,4,-2
```

对比同一机位的 `ms`，而不是对比不同视角。改动后必须复测，防止"优化"变慢。

## 移动端

- 默认 `guessQuality()` 已按 UA/核数判断，移动端直接 low
- 关闭 MSAA 与高分辨率阴影对移动端收益最大
- 雾、Bloom 保留，它们是"廉价的高级感"
