# 04 · 光照与后处理

先定光，再定后期。光错了，后期只会把错误放大。

## 主题字段

```js
{
  sky: 0x2c3a44,                                  // 背景色
  fog: { color: 0x33424c, density: 0.0075 },      // 指数雾，越大越近
  sun: { color: 0xffd2a0, intensity: 3.1, dir: [-0.55, 0.42, -0.72] },
  hemi: { sky: 0x9fb9cc, ground: 0x2a251f, intensity: 1.5 },
  env: { intensity: 0.85, top: 0xa8c4dc, mid: 0x6a7f92, bottom: 0x3a322a },
  shadow: { size: 14, near: 1, far: 220 },        // 室内必填，外景可省略（默认 ±80）
  ao: { intensity: 1.35, radius: 0.42 },          // 室内加深接触阴影
  exposure: 1.05,
  wetness: 0.45, grime: 0.62,
  post: { bloom: 0.55, saturation: 0.95, vignette: 0.36, ca: 0.012, grain: 0.055 },
  palette: { ... }                                // 顶点色来源
}
```

`env` 会生成一张渐变 IBL（PMREM）。**没有它，金属度与湿润高光只能反射黑色，夜景会整片糊死**，这是夜景最常见的翻车点。`env.intensity` 控制环境光占比：户外 0.7–0.9，夜景 1.2–1.6，室内 0.6–1.0。

`shadow.size` 是太阳正交阴影相机的半边长。室内 12–18 米就能让 4096 阴影图覆盖全屋，门框与窗挺的投影才清楚；外景用默认 80。

`ao.radius` 是世界单位的采样半径，室内 0.35–0.5，外景 0.5–0.9；`ao.intensity` 1.0–1.5，超过 1.6 会在缝隙里出现黑边。AO 由深度重建，会关闭 MSAA。

## 体积光的两条路线

| 方案 | 适用 | 用法 |
|---|---|---|
| 屏幕空间径向光柱 | 太阳/强光源在画面内，如外景逆光、夜景霓虹 | `theme.rays = { strength, density, decay, threshold }` |
| 几何光片 | 室内、窗户、灯口、隧道口 | `kit.shafts.add({ pos, width, length, dir, color, intensity })` |

**室内不要用屏幕空间光柱**：窗户是一块高亮矩形，径向模糊会把它拖成条状伪影，看起来像贴图错误。光片是加法混合的双面片、不写深度、沿长度和横向渐隐，稳定且便宜。

光片参数经验值：长度 6–10 米，宽度略小于窗宽，方向与太阳入射方向一致（`dir` 指向室内下方），intensity 0.15–0.3；太亮会变成实心光柱。

## 运动模糊

相机运动模糊：用当前深度重建世界坐标，投影回上一帧的 view-projection 得到屏幕速度，沿速度方向做 8 次采样。

```js
motion: { shutter: 0.25, maxVel: 0.02 }
```

- 只支持**相机运动**，不支持物体运动（程序化场景里基本够用）
- `shutter` 0.2–0.4；`maxVel` 是屏幕空间最大位移比例，超过会出现长条拖影
- 采样时按深度差加权，避免前景被背景拖影
- 相机静止时速度趋零，自动不产生模糊

## 太阳方向

`dir` 是从原点指向光源的方向（y 必须为正）。

| 时间 | dir | 强度 | 色温 |
|---|---|---|---|
| 清晨 / 黄昏 | `[-0.6, 0.25, -0.7]` | 2.4–3.4 | 暖 `0xffd2a0` |
| 正午 | `[-0.3, 0.9, -0.4]` | 3.6–4.5 | 中性 `0xfff4e2` |
| 阴天 | `[-0.4, 0.7, -0.5]` | 1.2–1.8 | 冷 `0xcfd8e0` |
| 夜晚 | `[-0.3, 0.55, -0.8]` | 0.6–1.2 | 冷 `0x8ea8ff` |

太阳越低，阴影越长，越容易出"电影感"；但阴影相机范围要随之加大。

## 雾

- `density` 0.004–0.008：外景，能见度 100–200 米
- 0.010–0.016：夜雨、狭窄街区，压迫感
- 雾色必须与天空色接近，否则远景会出现"墙"

## 后处理参数

| 参数 | 合理范围 | 作用 |
|---|---|---|
| `bloom` | 0.35–1.2 | 发光件扩散；夜景调高 |
| `saturation` | 0.8–1.15 | <1 更"电影"，>1 更"游戏" |
| `vignette` | 0.25–0.45 | 压暗四角，聚焦中心 |
| `ca` | 0.005–0.02 | 色差，>0.02 会明显变形 |
| `grain` | 0.03–0.06 | 颗粒，掩盖低模的"太干净" |
| `exposure` | 0.85–1.3 | 整体亮度，先调它再调光强 |

顺序建议：曝光 → 太阳强度 → 雾 → Bloom → 暗角 → 颗粒。

## 管线结构

```
场景(HDR) → 高光提取 → 高斯模糊(1–3 次) → 合成(色差/曝光/ACES/饱和/暗角/颗粒/γ)
```

修改管线要谨慎：新增通道意味着所有场景都要为该通道调参。

## 三套基准主题

| 主题 | 关键参数 |
|---|---|
| 港区晨雾 | 暖低角度光、湿 0.45、雾 0.0075、Bloom 0.55、env 0.85 |
| 雨夜霓虹 | 冷光 1.9、湿 0.98、雾 0.0085、Bloom 1.05、env 1.35、曝光 1.5 |
| 地下设施 | 顶光 2.6、湿 0.2、雾 0.009、Bloom 0.7、env 0.9 |

新主题从这三套里选一套做基底，再改 3–4 个参数，不要从零开始。

## 验收

- 画面里必须能看出"光从哪来"
- 阴影方向一致，没有悬浮物体的假影
- 暗部不是死黑：`grain` 只在有亮度处生效，暗部靠 `hemi` 与 `env` 抬起来
- 发光件附近有 Bloom，但不糊成一片
- **夜景自检**：先看 `env.intensity` 是否 ≥1.2、曝光是否 ≥1.4，再看 Bloom；不要用 Bloom 掩盖欠曝
