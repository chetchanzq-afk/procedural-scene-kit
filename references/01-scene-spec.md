# 01 · 场景规格

先写规格再写代码。规格是主题、道具、布局、预算的唯一来源，避免边写边改导致比例失真。

## 结构

```json
{
  "title": "雨夜赛博小巷",
  "genre": "street",
  "scale": { "width": 24, "depth": 60, "height": 12 },
  "time": "night",
  "weather": "rain",
  "mood": "压抑、潮湿、霓虹反射",
  "palette": {
    "primary": "#2b3a4a",
    "secondary": "#39d7e8",
    "accent": "#ff4fa3",
    "ground": "#22262e"
  },
  "requiredProps": ["楼体", "卷帘门", "雨棚", "招牌", "管道", "垃圾箱", "电线"],
  "counts": { "buildings": 6, "signs": 10, "pipes": 4 },
  "performance": "medium",
  "camera": { "position": [-8, 2.2, 18], "lookAt": [0, 2, -6] },
  "forbidden": ["角色", "植被", "外部贴图"]
}
```

## 需求到参数的映射

| 需求词 | 参数落点 |
|---|---|
| 夜 / 黄昏 / 清晨 | `time` → 主题的太阳高度与色温、曝光 |
| 雨 / 雪 / 雾 | `weather` → `wetness`、雾密度、Bloom 强度 |
| 赛博 / 工业 / 废弃 | 调色板饱和度、污渍强度、发光件数量 |
| 狭窄 / 开阔 | `scale` 决定道具密度与雾距 |
| 电影感 | 降低饱和度、加暗角、Bloom 集中在发光件 |
| 性能优先 | `performance: low` → 道具种类减少、合并更激进 |

## 尺度约定

- 1 单位 = 1 米，人眼高度 1.65
- 集装箱 12.19 × 2.59 × 2.44
- 门高 2.1，层高 3.2–4.5，栏杆高 1.05
- 相机 FOV 55–62，室内可用 70

比例错了，后面所有材质和光照都救不回来。

## 数量控制

| 场景规模 | 道具种类 | 实例数 | 三角面预算 |
|---|---|---|---|
| 小型室内 | 8–12 | 30–60 | ≤ 120k |
| 街区 / 堆场 | 12–18 | 50–120 | ≤ 250k |
| 大型外景 | 16–24 | 120–300 | ≤ 400k |

超过预算先减实例，再减分段数，最后才降画质。

## 交付前自检

- 规格里的 `requiredProps` 是否都实现了
- 相机起点是否能看到"最有信息量"的画面
- 是否出现了规格 `forbidden` 里的东西（尤其是角色与植被）
